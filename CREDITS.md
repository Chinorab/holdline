# Credits

- Sounds: every sound (crackle, wind, aircraft, digging, water) is synthesized in code at
  run time by `src/audio/synth.ts`. No recordings are used.
- Hand and controller models: WebXR Input Profiles assets, MIT license, hosted with the game
  (`public/input-profiles/LICENSE` and `SOURCE.txt`).
- Fire model: after Alexandridis et al. 2008 (constants as quoted by Freire and DaCamara 2019,
  NHESS 19, 169 to 179).
- Built with the Immersive Web SDK (Meta, MIT license) and three.js (MIT license).
